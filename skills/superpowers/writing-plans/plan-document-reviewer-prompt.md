# Plan Review Brief

Use within the project's independent document review policy and budget, without adding another review gate.

Compare the plan with the accepted requirements. Check coverage, dependencies, ownership conflicts, interface contracts, and meaningful verification. A bounded task needs no full code listing or 2-5 minute script. Do not require fresh implementers, per-task reviews, or renewed approval of an already accepted design.

Report concrete gaps and contradictions with evidence. Return no findings when the plan is sufficient to execute; cosmetic expansion is not a requirement.
