# Targeted Reviewer Brief

Optional format for a reviewer selected by the project's quality-check. This does not create a per-task gate or an extra review round.

- Scope: [current diff and concrete concern]
- Required behavior: [independent spec/reference]
- Evidence: [actual checks and expected results]

Inspect the relevant implementation and independent requirements. Verify suspected defects, distinguish blockers from suggestions, and report only actionable findings with location, severity, evidence, and source. Return an empty findings array if none. Follow the project's review budget.
