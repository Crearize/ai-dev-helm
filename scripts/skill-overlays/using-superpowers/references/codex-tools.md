# Codex Tool Adaptation

Use the tools and model names actually available in the current session. Their live descriptions and system/developer instructions override examples in skills. Do not require a machine configuration change merely to execute an authorized task.

Delegate only when useful and permitted. Choose context scope intentionally; pass a bounded brief when full conversation history is unnecessary. Respect the tool's restrictions on model/effort overrides instead of assuming every fork supports them.

While workers run, continue independent local work. When idle, use the available mailbox/wait mechanism with durations that preserve the required user progress updates. Follow the actual runtime's worker lifecycle rather than assuming close/resume operations exist.

Detect repository and worktree state before branch operations. Detached HEAD alone does not establish a permission restriction: use the platform's available authorized operations. Preserve externally managed workspaces. Follow project branch protections and existing user authorization for integration.
